# TS 宿主 ABI 3

原生模块 `dango:host` 为 QuickJS 提供有界同步调用、异步请求、数值延时和单调
时钟。包中的 ABI 与引擎指纹必须同时匹配当前固件；不匹配的包在读取字节码前
被拒绝。固件、默认 brain、应用及 worker 使用同一引擎构建。

## 请求与结果

通用调用的参数仍为 JSON 文本及可选二进制数据。成功结果在 C 桥中直接转换为
JS 值；返回模式分别为 JSON 值、二进制、无返回值和包含 `value`/`bytes` 的组合。
组合仅用于确实同时返回元数据和二进制的操作。服务失败携带 `code` 和 `message`，
异步调用通过 Promise 拒绝交付。

数值延时直接接收毫秒或微秒，进入带 `RequestId` 的类型化延时队列，不创建操作名、
参数 JSON 或成功结果对象。毫秒范围为 `0..u32::MAX`；微秒范围为 `0..1_000_000`。
参数必须是有限、非负的整数。零延时仍经过前台调度与按需 UI 提交屏障，然后完成
Promise。正延时以单调时钟确定截止时间。worker 使用相同数值协议。

同步单调时钟直接返回宿主提供的毫秒数。JSON 传输、JS 对象和裸指针均不参与
该路径。后台 brain 只使用其允许的同步接口，不能留下异步请求。

每个 VM 的 Promise 等待槽位在初始化时按 `pending_requests` 分配。完成或拒绝
请求后释放槽位中的 JS 引用并复用槽位；VM 销毁时释放所有剩余引用和槽位。
请求 ID 包含 VM 实例和递增序号，旧实例或已完成的请求不能恢复当前实例。
槽位容量、传输字节限制、VM 内存限制和执行预算分别保持独立。

worker 同步等待队列保留已分配容量，按 FIFO 检查就绪条件；活跃 worker ID 使用
八项栈数组，VM 产生的请求逐项处理。周期性轮询不再分配 ID 列表、请求临时列表，
也不销毁并重建仍在等待的同步队列。

## 调度与观测

运行器统一处理通用请求和类型化延时。UI、存储与 worker 完成后恢复相应 Promise；
停止与应用切换在有界 VM 操作之间生效。真实 IO 等待、UI 提交和纯合作式让出分别
统计，避免把等待时间当成 VM 指令执行时间。

运行时按 VM 累计同步调用、通用异步请求、类型化延时、Promise job 数，以及宿主
分派、请求入队、完成回复和 job 执行的耗时。嵌套宿主调用包含在 job 时间内，
这些耗时不能简单相加。指标在 VM 关闭前采集；采集日志不进入计时样本。

连续就绪的 Promise 续体累计工作达到 4 ms 后合作式让出；判断位于有界 VM 工作批次
返回处，阈值不保证单批次在 4 ms 内返回。持续工作累计 16 ms 后仍强制等待 1 ms。
停止信号在每轮检查，真正的 UI 提交、
帧发布和 IO 等待立即进入各自屏障，不受续体合并影响。

## 数值绘图通道

`draw(op, x0, y0, x1, y1, x2, y2, color, start, end)` 直接传递固定数量的标量。
操作和六个坐标为 int32，颜色为 uint32，角度为有限 double。桥接层不执行
字符串、布尔值或对象的隐式数值转换；无效输入在修改 framebuffer 前拒绝。
宿主复用通用绘图通道的同一光栅实现、状态检查和错误码，不建立第二套绘图算法。
SDK 的所有基本图形使用这个通道，不再创建或填充坐标数组和 JSON 文本。

帧发布缓存一个受原生图形预算约束的不可变快照。UI 持有快照时不能原地修改；
只有 `Arc::get_mut` 确认独占且尺寸匹配时才复用。复用时只复制脏矩形中的行，
没有脏区域时不申请或复制像素。旧消费者仍持有快照时，另建完整快照，保持旧帧
内容和指针有效；关闭显示时释放缓存。统计提供快照容量、累计申请次数和复制字节。
脏矩形直接携带 C 光栅器最多四项的内联副本，UI 从同一个发布快照借用 blit 视图。
发布阶段不申请矩形或 blit 列表，也不为每个矩形增加一次快照引用计数。

一个同步 VM 工作窗口只申请一次频率投票并测量一次，覆盖 worker、job pump 和
入口状态检查；投票在任何定时器、UI 或帧等待前释放。

性能验证使用相同算法、输入、让出次数和校验值，分别对照 SDK 延时、通用请求、
已完成 Promise、同步时钟及计算内核。内存验证同时记录请求/等待槽位、分配峰值、
关闭账本、SRAM/PSRAM 最大连续块和实际连续申请。设备耗时与主机耗时分别记录。

构建对照包含 C 的 `-O2`/`-O3` 以及 Rolldown 的 AST 压缩。AST 压缩保留函数、
类和属性名，不使用不安全的浮点重排；单纯缩短 JS 文本不计为运行时性能提升。
两种编译产物在同一最终固件上执行相同校验负载，再决定是否保留压缩配置。
